# ciplink bindings: C, C++ and C#

The Rust core is exposed as a C ABI (`crates/ciplink-ffi`, library `ciplink`, header
`crates/ciplink-ffi/include/ciplink.h`, generated by cbindgen). Two wrappers sit on top of it:

| Language | Where | What |
|---|---|---|
| C | `crates/ciplink-ffi/include/ciplink.h` | Opaque handles, status codes, JSON text for values |
| C++17 | `bindings/cpp/include/ciplink.hpp` | Header-only RAII wrapper: `ciplink::Logix`, `Slc`, `Cip`, exceptions |
| C# (.NET 8+) | `bindings/dotnet/Ciplink` | P/Invoke wrapper: `LogixDriver`, `SlcDriver`, `CipDriver`, `IDisposable` |

All three drive the same core as the Python package, so requests on the wire are the same byte for byte.

## Building

```sh
cargo build --release -p ciplink-ffi            # target/release/ciplink.dll (or libciplink.so / .dylib), plus a static lib
cd crates/ciplink-ffi && cbindgen --config cbindgen.toml --crate ciplink-ffi --output include/ciplink.h
bindings/cpp/build_and_test.sh                  # C++ tests and example against two simulators
cd bindings/dotnet && dotnet test               # C# tests (uses the library in target/release)
```

The tests run against `ciplink-sim` (`cargo run -p ciplink-sim -- --config tools/sim/example_controller.json --port 0`),
never against a real controller.

## The C ABI in short

- **Handles.** `ciplink_logix_new`, `ciplink_slc_new` or `ciplink_cip_new` make a `CiplinkDriver*`, and
  `ciplink_driver_free` closes and frees it. Nothing connects until `ciplink_open`. A handle can be shared by threads,
  because calls are serialized inside the driver.
- **Status.** Every call returns a `CiplinkStatus`, where `CIPLINK_STATUS_OK` (0) is success. The other values are
  `COMM`, `DATA`, `RESPONSE`, `REQUEST`, `INVALID_ARGUMENT` (NULL, bad UTF-8 or bad JSON), `UNSUPPORTED` (the call
  does not apply to this driver kind) and `PANIC` (a library bug; the handle stays usable).
- **Errors.** `ciplink_last_error(NULL)` gives the calling thread's latest failure. `ciplink_last_error(handle)` gives
  the handle's latest failure. Either returns NULL if there was none.
- **Memory.** Every `char*` the library returns is freed with `ciplink_string_free`. Raw reply frames
  (`uint8_t*` + length) are freed with `ciplink_bytes_free(data, len)`. On failure, out pointers are left NULL.
- **Values** are UTF-8 JSON:

  | Type | JSON form |
  |---|---|
  | BOOL | `true` / `false` |
  | Integers | numbers (full 64-bit range) |
  | REAL / LREAL | numbers with `.` or `e`; NaN and infinities are `{"$float": "NaN"}` |
  | STRING | strings |
  | Raw bytes | `{"$bytes": "<hex>"}` |
  | Arrays | arrays |
  | Structures | objects in member order |

- **Tag results.** Each result is `{"tag", "value", "type", "error"}`. `error` is null on success, or
  `{"message", "kind", "status", "ext"}`. `kind` is one of `not_found`, `bad_value`, `bad_request`, `access`,
  `refused`, `table_changed`, `comm`, `device` or `other`. A failure on one tag is data in the result, so the call
  still returns OK.

### Options (JSON, all optional)

| Key | Drivers | Default | Meaning |
|---|---|---|---|
| `socket_timeout` | all | 5 | Seconds, or `null` to block forever |
| `connection_size` | all | 4000 (SLC 500) | Size of the Forward Open; above 511 uses a Large Forward Open |
| `init_tags` | Logix | true | Upload the tag list on open |
| `init_program_tags` | Logix | true | Include program-scoped tags |
| `tag_namespace_filter` | Logix | `""` | Only upload tags whose name starts with this |
| `lazy_tags` | Logix | false | Look tags up on first use instead of uploading all of them |
| `tag_cache_file` | Logix | null | File to cache the uploaded tag list in |

A call made on a driver kind that does not support it returns `UNSUPPORTED`. In C++ that is `ciplink::Error`, and in
C# it is `CiplinkException`.

### Rules for the newer calls (the same as the Python driver)

- **Connection size** applies to the next Forward Open. It can change only while the CIP connection is closed;
  changing it while connected returns `REQUEST` with "Close the connection before changing connection_size". 0 is
  `INVALID_ARGUMENT`.
- **Socket timeout** must be a positive finite number of seconds. A negative value means block forever (`None` in
  Python). 0, NaN and infinity are `INVALID_ARGUMENT`. A new timeout applies to an open connection straight away.
- **Raw sends** pass a CIP message through unchanged: the service, request path and data. A connected message has
  no sequence count, because the driver adds its next one. Neither call opens anything. The connected call needs an
  open CIP connection (a Logix `open` makes one), and the unconnected call needs a session. The result is the whole
  reply frame, encapsulation header included, unchecked. A dropped connection is `COMM`.
- **Tag list.** `program` is NULL for controller tags, `"*"` for all, or a program name. With `cache` the list
  replaces the handle's tag definitions. Without `cache` they are left as they were. `tag_namespace_filter` (NULL or
  `""` for none) keeps the names that start with it, ignoring any `Program:X.` prefix.
- **Device browsing** works like RSWho. A route is relative to the device at the driver's IP address: NULL or `""`
  is that device, `"bp/3"` the module in slot 3 of its backplane, `"bp/2/enet/192.168.1.10"` a device behind the
  module in slot 2. A port's `nodes` are the addresses a browse probes: its slots or nodes, or every host of an
  EtherNet/IP port's subnet (at most a /24). `nodes_json` NULL probes those, or pass a JSON array of addresses.
  Each empty slot or missing device may cost the bridge's ~4 s timeout, so `workers` connections of their own probe
  at once. `ciplink_scan_port` calls `callback(user, node_json)` on the calling thread as each node answers, in any
  order, until it returns false; `node_json` is valid only during the call, and the callback must not unwind.
- **Metadata authentication.** Pass both buffers as NULL to use the bundled credentials, or pass both a signed
  certificate and its unencrypted PKCS #1 or PKCS #8 DER RSA private key. Passing only one is `INVALID_ARGUMENT`.
  Credentials that do not parse or do not match each other are `REQUEST`. A handshake the controller refuses is the
  result's `error`, not a failed status. Authentication covers the current connection only, so call it again after a
  reconnect.

- **Tag server.** `ciplink_server_start` runs the tag server of a config file (see `docs/server.md`) on threads of
  its own and returns once it listens. Its options are `mock` (simulated values from each PLC's `mock_tags` file),
  `host` and `port` (they override the config's; port 0 picks a free port). A config that can't be read or is wrong
  is `INVALID_ARGUMENT`; a port that is taken is `COMM`. `ciplink_server_stop` releases pressed momentary buttons,
  closes the PLC connections and flushes the audit log before it frees the server.

## C example

```c
#include "ciplink.h"
#include <stdio.h>

static int fail(const char *what) {
    char *msg = ciplink_last_error(NULL);
    fprintf(stderr, "%s: %s\n", what, msg ? msg : "?");
    ciplink_string_free(msg);
    return 1;
}

int main(void) {
    struct CiplinkDriver *plc = NULL;
    char *json = NULL;
    if (ciplink_logix_new("192.168.1.10/0", "{\"socket_timeout\": 3}", &plc)) return fail("new");
    ciplink_set_connection_size(plc, 4000); /* before open */
    if (ciplink_open(plc)) return fail("open");

    const char *tags[] = {"Counter", "Recipe.Speed"};
    if (ciplink_read(plc, tags, 2, &json) == CIPLINK_STATUS_OK) {
        printf("%s\n", json); /* [{"tag":"Counter","value":42,"type":"DINT","error":null}, ...] */
        ciplink_string_free(json);
    }
    if (ciplink_write(plc, "[[\"Setpoint\", 12.5]]", &json) == CIPLINK_STATUS_OK) ciplink_string_free(json);

    /* one program's tags, without replacing the cached definitions */
    if (ciplink_tag_list(plc, "MainProgram", false, NULL, &json) == CIPLINK_STATUS_OK) ciplink_string_free(json);

    /* raw Get Attribute Single of the identity's product code */
    const uint8_t request[] = {0x0e, 0x03, 0x20, 0x01, 0x24, 0x01, 0x30, 0x03};
    uint8_t *reply = NULL;
    size_t reply_len = 0;
    if (ciplink_send_unconnected(plc, request, sizeof request, &reply, &reply_len) == CIPLINK_STATUS_OK) {
        printf("reply frame of %zu bytes\n", reply_len);
        ciplink_bytes_free(reply, reply_len);
    }

    /* metadata authentication with the bundled credentials (or pass certificate and DER key buffers) */
    if (ciplink_authenticate_metadata(plc, NULL, 0, NULL, 0, &json) == CIPLINK_STATUS_OK) ciplink_string_free(json);

    ciplink_driver_free(plc);
    return 0;
}
```

## C++ example

```cpp
#include "ciplink.hpp"
#include <iostream>

int main() {
    try {
        ciplink::Logix plc("192.168.1.10/0", R"({"socket_timeout": 3})");
        plc.set_connection_size(4000);  // only while closed
        plc.open();
        plc.set_socket_timeout(10.0);   // applies to the open connection

        for (const ciplink::Tag& t : plc.read({"Counter", "Recipe.Speed"}))
            std::cout << t.tag << " = " << (t ? ciplink::to_json(t.value) : t.error->message) << "\n";
        plc.write_tag("Setpoint", 12.5);

        std::string program = plc.tag_list_json(std::string("MainProgram"), /*cache=*/false);
        std::string speeds = plc.tag_list_json(std::nullopt, false, /*tag_namespace_filter=*/"Speed");

        std::vector<uint8_t> frame = plc.send_unconnected({0x0e, 0x03, 0x20, 0x01, 0x24, 0x01, 0x30, 0x03});

        std::vector<uint8_t> cert = load("metadata.cert"), key = load("metadata.der");  // your own loader
        ciplink::Tag auth = plc.authenticate_metadata(cert, key);  // or authenticate_metadata() for the bundled ones
        if (auth) std::cout << plc.get_tag_description("Counter").value.as_string() << "\n";
    } catch (const ciplink::Error& e) {
        std::cerr << "error " << int(e.status()) << ": " << e.what() << "\n";
        return 1;
    }
}
```

## C# example

```csharp
using Ciplink;

using var plc = new LogixDriver("192.168.1.10/0", new LogixOptions { SocketTimeout = TimeSpan.FromSeconds(3) });
plc.ConnectionSize = 4000;                  // only while closed
plc.Open();
plc.SocketTimeout = TimeSpan.FromSeconds(10);

foreach (Tag t in plc.Read("Counter", "Recipe.Speed"))
    Console.WriteLine(t.IsOk ? $"{t.Name} = {t.Value}" : $"{t.Name}: {t.ErrorKind}: {t.Error}");
plc.Write("Setpoint", 12.5);

var program = plc.TagList("MainProgram", cache: false);
var speeds = plc.TagList(cache: false, tagNamespaceFilter: "Speed");

byte[] frame = plc.SendUnconnected(new byte[] { 0x0e, 0x03, 0x20, 0x01, 0x24, 0x01, 0x30, 0x03 });

Tag auth = plc.AuthenticateMetadata(File.ReadAllBytes("metadata.cert"), File.ReadAllBytes("metadata.der"));
if (auth.IsOk) Console.WriteLine(plc.GetTagDescription("Counter").Value);
```
